## 哪些起点能被原 Actor 区分

两侧各取 nominal 及 C02–C09、C18–C20，共 24 个真实重建的起点。初始历史重复该起点的实际状态，上一动作置零。每个起点在自己的 Warp 反馈上产生 51 个动作，共推进 500 个 2 ms 子步。初始 q/v 与旧逐案记录逐元素一致。CPU 上的冻结 Actor 给出同一参数化下的动作。此试验覆盖开始的 1 s。

| 开发条件 | 对照 nominal 的初始信息 | 实际动作 |
| --- | --- | --- |
| C02–C05、C19 | 两侧的原始本体历史与 540 维 Actor 参考完全相同。570 维 WM 参考因根相对平移而改变 | 首动作相同，首秒归一化动作变化约 1e−7 |
| C06、C07 | 两侧的本体历史相同，参考方向因 ±5° 偏航改变，最大分量差约 0.08716 | 首动作最大变化分别约 0.000253 与 0.011621 |
| C08、C09 | 两侧的历史、540 维参考与含相对根平移的 570 维参考均相同。把手相对 TCP 的世界坐标向量最大分量差，前拉为 25.21/62.74 mm，背推为 25.33/63.46 mm | 首动作完全相同，首秒最大差不超过 1.12e−7 |
| C18、C20 | 组合条件的偏航已改变原 Actor 的参考。C19 单列在平移组 | C18、C20 的首动作变化与相应偏航方向相同，不能由此断定网络利用了门初角或平移 |

从准确的当前根相对参考补入平移可以区分 C02–C05。门初角仍需要另一项信息。这里的几何来自仿真状态。命令为 `OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 bash scripts/b0/env.sh python -m scripts.b0.recovery_start_inputs`；数值、首动作分组、逐案此前的完整失败与读回的 Warp 缓冲信息记录在 `results/b0/recovery_a_observation_r1/{pull,push}.json`。

## 训练和验证回合

PCG64 种子 231123 预先确定每侧六个训练回合与两个验证回合，涵盖平移、偏航、门初角及组合。平移各轴在 ±45 mm 内，偏航在 ±4.8° 内，抽样门初角在 0.3–4.8°。未选中的扰动量保持名义。每个回合从自己的初态连续推进，用 P6 闭环教师每十个物理步选一次目标，其间保持目标恒定。保留原力、接触、限位、时长和两个独立停车判据。训练时钟固定在同侧名义参考，不给每条扰动场景准备参考。两个组合训练回合在抓持 hold 开始后请求开口 2 个 20 ms 区间，再恢复普通指令。两个组合验证回合请求 16 个区间；真实硬失败会提前终止。短步终止在有限且可步进时，沿用已下发的同一目标补到下一个 20 ms 真实后继。

完整的注册、条件身份与独立划分在 `config/b0/recovery_a_teacher_r1.json`。复现入口为 `bash scripts/b0/env.sh python -m scripts.b0.recovery_teacher --episode <已登记且尚未采集的ID>`。追加 `--index` 在已有完整源回合上重建监督掩码，不进行物理步进。前四个回合的原始数据在第二平台 `/home/kaiwen/research/dog-and-arm-b0-contact/results/raw_large/b0/recovery_a_teacher_r1`；后十二个在 AutoDL `/root/autodl-tmp/dog-and-arm-b0-recovery/results/raw_large/b0/recovery_a_teacher_r1`。云端同一目录另有前四个回合用于配对训练的 50 Hz 字段、元数据与掩码。两台机器的固定参考配置一致，所检 qpos、qvel、动作、步号与阶段数组的形状和首/中/末样本一致。两台主机均使用固定 SuperMimic/mjlab 源码以及 MuJoCo/MuJoCo-Warp 3.16.0；GPU 型号与驱动有别，详细记录见 `site_check.json`。

`bc_positive_mask.npy` 要求有效 20 ms、与名义库此刻阶段名称相同、尚在有效参考内、未执行开口干预且该区间未发生真实硬失败。按 `physics_step` 对齐真实状态和后继。所有排除的样本仍在原始回合中。阶段相同只能过滤明显的错位，并不能保证 TCP 目标一致。

## 扰动教师在冻结完整任务裁判下的表现

使用 `bash scripts/b0/env.sh python -m scripts.b0.score_recovery_teacher_clock --episode <ID>`，将记录中的每个 2 ms 区间交给与策略评测相同的 `ContactEvents`。FK 使用区间起点重建几何，限位使用已记录的后继状态。门力、双指与车轮载荷、滑动、意外接触类别和执行器力均直接读取求解器记录，无二次物理积分。原始数据未导出 Warp 的原生 warning 计数。该复核衡量一条教师轨迹与冻结裁判是否相容。

名义参考自身通过，前拉和背推分别在 37,368 与 27,528 个物理步满足完整判据。两条第一组 XY 扰动教师用自己的 P6 时序均完成，但冻结裁判在终点仅积累 1,141/1,500 与 1,453/1,500 个有效停车子步，均耗尽同侧参考。第二组 XY 中，背推在冻结时钟下通过，前拉只积累 529 个有效停车子步。这些结果说明可用的停车余量依赖初态和真实驶近速度。

带门初角的训练例揭示另一种冲突。前拉第 02 个回合的门初角为 4.117°。教师在 `pregrasp` 末端距其自身目标 0.028 mm，距冻结名义端点却有 52.322 mm。冻结裁判要求 3 mm，实际在 17.620 s 预抓超时。背推对应回合的两项距离为 0.028 和 55.873 mm，于 18.816 s 超时。两条教师在自己的 P6 事件下均完成全程。在两条轨迹与名义记录都标为 `pregrasp` 的时段，即使使用同一整数时钟，目标位置差的中位数也约为 0.36 m，其中还包含接近轨迹进度差。这些扰动数据适合分开诊断闭环几何、模型与纠偏动作，不能将每一条同相位动作均视为满足冻结裁判的示范。

实测明细位于 `results/b0/recovery_a_teacher_r1`。每个 ID 的 JSON 含 P6 结果及首次失败物理区间，`*_clock.json` 给出各阶段的整数步时差和有效标签数，`judge/<ID>.json` 给出完整冻结裁判的首次失败、各阶段连续窗口、真实与目标端点的距离。教师成功率和冻结裁判重放均不计入学习 Actor 的 C 开发成绩或 H32 更新。
