## 1. 优先交付 V0：首次真实完整成功视频

标准学习Actor从原任务frame 0连续完成任一侧nominal，就立即生成并交付该侧完整视频，随后在同一轮继续另一侧。**首次视频不等待D/C、三seed或H全部验收完成，也不以前置十片段全部通过来禁止完整名义开发尝试。** 视频里程碑V0与最终标准基线资格分别记账；一侧成功不得写成双侧已完成，也不替代0.90参照／0.88接近带或原正式物理门槛。

完整任务依原FULL_DOOR_PHASES：驶近、停车、伸臂、抓持、开门、保持、释放、撤臂、收臂、退离与最终停稳；具体顺序、目标角度和时限读冻结参考/裁判。前拉与背推分别使用原目标，不能为视频临时缩短任务。

单条原始视频对应同一个冻结checkpoint、一次episode、连续物理积分。每20ms依据真实后继调用Actor，无阶段重置、教师接管、参考动作尾段、直接驱动门或事后拼接成功片段。保留从初始到终态的全部时间；同步侧视与腕视可以并排。另做加速展示片时标倍率，并保留连续原速版。双侧汇总片标清两次独立episode边界。

原裁判判定通过、完整阶段事件与真实状态轨迹闭合后，文件才命名为success。失败尝试保留首次失败与已完成阶段，不能把计分结束后的诊断尾段命名为成功。旧P6教师、540/546混合策略以及现有三入口拼接诊断视频不替代V0。

## 3. 参数与指标按同定义比例比较

同时报告绝对值、单位、分母来源和比例，不只给pass/fail。

| 项目 | 比例与分母 | 使用限制 |
| --- | --- | --- |
| WM保持 | E/E0、E/历史开发参考线，固定同一验证窗与分层 | 旧1.25E0和50mm均为项目额外诊断线；下一轮不据此阻断官方Actor更新 |
| 原状态误差 | q/v/位置/姿态误差分别除以各自登记nominal error | 不把TCP毫米直接比论文归一化0.007–0.011 |
| 力与执行器 | 门力/该阶段原阈值；实际和未裁力绝对值/各路force limit | 非6N适用阶段不得统一套6N；线力N和力矩Nm分别列 |
| 伺服各项 | kp·abs(target−q)/L、kv·abs(v)/L、abs(cached bias)/L | 使用solve前真实状态、主动指坐标和实际缓存 |
| 脱饱和距离 | rad/mm，同时除以0.25L/kp基础effort单位和真实采集σ | jaw全开度映射单独×2；边界随状态变，不是推荐固定命令 |
| 参考支持 | 训练参考q/v/命令范围、实际Actor范围、缺口/训练跨度 | 常值列跨度为0时标NA，保留绝对缺口，不能编造比例 |
| 任务进度 | 门角/该侧目标门角、有效存续/原计划时长、逐阶段事件 | 不是总体完成百分比；仅存活不等于抓持/开门 |
| 时间尺度 | policy/servo=10、servo/physics=8（训练）、H32物理时长0.64s | 原2ms正式与细步训练分别报告 |
| 完整回报 | 原整段归一化物理回报、相对0.90与0.88的差值 | 无完整评分记NA；0.90是论文SONIC参照，跨任务不冒充同benchmark |
| 学习与成本 | 新增/继承H32、WM/Critic、有效转移、真实物理步、训练时长 | 不把预热或未执行Ratio额度计作Actor更新 |

训练流程遵循[官方对齐矩阵](B0_OFFICIAL_FLOW_ALIGNMENT_20261124.md)和[执行计划](B0_FULL_TASK_TRANSFER_PLAN_20261124.md)。采集、WM/Actor统计更新、Ratio、10个H7 WM批、H32 Actor/Critic连续进行，不以额外25%或50mm验证误差门阻断Actor；误差和失败仍如实诊断。H1混合、离线配额、冻结统计、batch、学习率、gain32等本项目配方须逐项对照处置，不能因保留原网络而统称原样官方。

不因“按比例比较”就按机器人长度/质量盲改PD、力限或6N。若比较自然频率/阻尼比，先取得对应姿态有效关节惯量，再计算；这不是当前默认参数修改。没有匹配物理量/分母时明确不可比。
