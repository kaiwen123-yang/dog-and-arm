## 2. 唯一信息变化与代码入口

令当前策略查询时刻为 t，参考根位置为 p_ref(t)，当前真实／想象根位置为 p(t)，当前根 yaw 为 ψ(t)：

```text
xy_world = p_ref(t)[:2] - p(t)[:2]
xy_body  = Rz(yaw(t)).T @ xy_world
feature  = xy_body / 0.05 m        # treatment
feature  = [0, 0]                 # zero-information control
goal542  = concat(original_normalized_goal540, feature)
```

这里的 t 是当前 Actor 查询时刻，不是 reward 的 t+1 目标。只用当前参考根和当前自身根，不加入冻结预抓端点、把手、门角、裁判 phase、未来实测状态或额外 30 维未来平移。不增加 feature clipping。仿真 root 真值代表理想自身定位；实机定位误差和延迟尚未验证。

**`cfg.execution_recipe` 必须继续为 `official_flow_s0_v1`。** 当前 `ContactRun`、采集器和 replay 根据该字符串选择官方分支，不能拿新 method ID 替换它。新方法、goal schema、`feature_mode=measured|zero` 使用独立字段。542 仅用于 Actor；WM representation75、goal570、context5，以及 Critic 输入、网络和 loss 均不变，避免共享 helper 把额外信息误传到其他网络。

使用一个共享特征构造入口覆盖以下路径，并记录实际 schema、列序和单位：

| 路径 | 必须满足的语义 |
| --- | --- |
| 真实采集 | 查询 Actor 当拍，由当前真实根和当前参考 frame 计算；原 history、上拍动作和传感噪声保持。 |
| Replay 初态 | 从已有 state、motion_time、history 因果重算；不增加未来标签或新离线数据。 |

### 4.2 +200 后的有条件推进

为避免仅发布一个微小试验就再开一轮，预登记**两支同步延长到各 +1000**，但只在 +200 原物理证据满足下列条件时执行。这是本项目预算条件，不是官方训练课程，也不修改正式成功线。

先用已完成的 +0／+200 三个包各四个 full 判断是否可能满足条件；只有有实质候选时，再逆序复测这三个包各四案，共 **12 条额外 full**。首遍属于正式节点评测，第二遍单列为延长复测；不能把重复当独立 seed 或泛化成功率。

- 处理支在 Warp 两侧都保持原驶近／停车，且相对共同 +0 **和**零控制出现原预抓进展。进展按以下三个 OR 分支判定：同一原裁判回合的已完成事件级别在两遍中都严格高于两个对照；或在完整固定平台上，处理支两遍 P95 的最大值小于两个对照各自两遍 P95 的最小值，同时最长 ready 和位置合格拍不劣于对照；或处理支两遍较小的最长同时 ready 严格超过两个对照各自两遍的较大值，且完整固定窗 P95 相对任一对照都无可区分退化。P95 改善分支允许 ready 仍为 0，不把首次跨过 3 mm 设成额外训练前置。两遍之间仅有数值波动重叠、只改善最近一帧、单侧改善，均不足以延长。报告实际 mm／3 mm 比例和效果量，不能只给布尔决定。

## 6. 并行一次冻结 FP64 检查，不再开独立 WM 轮

原记录中 H32 的 WM AD 与同一 WM 中心割线为 25 同号／9 反号／2 低分辨，9 个反号全在背推。WM 与真实物理割线的 20／8／8 是另一项比较。原一 ULP 展示线和未记录到模式切换，都不足以证明 32 步递归数值误差可忽略或函数光滑。因此保留一个有限的模型内复核，与配对实现／训练并行，不作为 WM 误差前置。

固定原 u10000、原 540 维 Actor、四个已存细步锚点、归档 z0／噪声／三条方向。方向只升为 FP64，不重新挑方向；所有浮点网络、buffer、normalizer、表示常量、状态／历史／动作／context／reference 均升为 FP64，离散索引不变。冻结统计与参数，不调用优化器。

```text
eta = 0.02 * 2**(-k), k = 0..10
4 anchors * 3 archived directions * 11 scales * 2 signs = 264 WM rollouts
另有 4 次预热、8 次 baseline、12 次方向 JVP、4 次 grad(J32,z)
新增物理 = 0；新增优化 = 0
```

每次 forward 保留全部 32 步的目标前缀、必要状态／动作和分项，用于从现有输出定位最早差异；同次输出 H1／H7 前缀、H32 前缀／Critic／总目标、八个 reward 分量与生存权重，核对分项求和、`grad·d` 与 JVP。保存双侧 Taylor 残差、中心和单侧斜率、相邻尺度变化；至少观察三个连续尺度的收敛趋势及后续舍入平台，不把低分辨当通过。重复 baseline 与 FP64 spacing 只作经验分辨率参考，不当严格误差界。

若稳定 FD 仍不趋近 AD，利用这些已保存分步／分项输出定位最早差异并交付最小反例；不自动追加物理或无限缩步。只在证明实际训练核心有实现违约时，封存受影响配对边界，将修复单独标识，不能把第二个干预混进 RefXY2 两支。若只是诊断代码问题则修复诊断，不改训练。仍 unresolved 时照实保留；FP64 eager 检查也不能单独证明 FP32 编译路径或真实物理导数正确。
