## 4. 参数与指标怎样按比例比较

使用各自有意义的物理分母，不给项目一个虚构的总完成百分比，也不为了数字好看改变原阈值。

| 量 | 比例／单位 | 能说明什么 |
| --- | --- | --- |
| 预抓位置 | 实测 mm／3 mm，另报绝对多出的 mm | 当前指定端点几何缺口；不能替代连续就绪 |
| 连续就绪 | 最长同时 ready 拍／75，或 ms／150 ms | 原裁判连续条件；当前四案都是 0 |
| 适用片段门力 | N／该原片段门力阈值，例如 6 N | 该片段约束余量；不把所有阶段统一改成 6 N |
| free | 每参考 TCP RMSE／30 mm，成功数／20 | 三类参考分别比较；不能与预抓最小端点距离互换 |
| 关节与夹口 | rad、m、固定 effort 坐标及其原尺度 | 与物理动作／单位对齐；不以不同关节裸数值相加 |
| 新 RefXY2 | 当前根相对参考 XY／0.05 m | 仅新 Actor 信息的固定尺度，不是将任务容差放大到 50 mm |
| 训练时间尺度 | 0.25 ms物理、2 ms伺服、20 ms策略；H32=640 ms | 各分支与原迁移的物理／学习时钟一致 |
| 计算成本 | 新增／继承／回滚的优化步、实际有效转移与墙钟分别列 | 不能只报有利末点或把失败回滚藏掉 |
| 论文回报 | 原协议的合格完整归一化回报 | 0.90 为既定 SONIC 参照线，0.88 为项目 0.02 接近带；不是原论文 SuperMimic 的最佳值 |

不同机器人、任务、动作空间、WM warm-start 与观测适配都要披露；论文 WM 的无量纲误差不能直接与本项目 TCP 毫米误差相比。当前 NA 不是 0，不能计算“距离 0.88 还差 0.88”。首次视频、完整双侧资格、独立 seed/H 和合格回报是不同里程碑，分别报告。
