- native背推完整停车最长770ms/1s，差230ms；连续段中断不能把多个短段相加补足。
- 末点三个进入预抓取的完整回合，最佳连续就绪0/150ms；具体位置/姿态欠项要补原有日志，不能用“距把手多少毫米”替代端点误差。
- J2上端命令缺口已从u1000的参考跨度59.6%降至新段1.031%，夹口覆盖0–100mm。范围改善已发生，下一重点是正确时机和连续物理行为。

## 4. “官方迁移”的准确含义

固定官方网络组织、GenCoord、原目标、在线统计与采集/Ratio/H7/H32主环保持；M1/Piper机器人维度、混合动作、参考、被动门和独立裁判是有记录的平台适配。B0阶段、预算、门任务判据并非论文作者给出的训练课程。初次WM有14850批祖先成本，当前是该谱系的连续恢复，不能称全部从零或原G1任务的同benchmark复现。

0.90是既定协议采用的论文SONIC参照，0.88是项目接近带；跨机器人/任务的数值相近仍需声明可比性边界。用户的标准迁移目标保持，后续算法和多模态/VLA仍在其完成并冻结之后。
