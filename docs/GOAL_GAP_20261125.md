## 4. 如何按比例比较

当前多模态主线优先报告完整任务成功数/全部尝试、同初态指令目标达成、已见/保留场景分组、非预期接触与失败阶段，以及训练数据量和实际计算成本。监督基线与加入WM优化的方法采用相同任务/观测/评测清单，收益既报百分点差也报绝对分母；视觉、深度、语言和全身协同贡献分别验证。下面桌面物理比例继续供用户日后实测使用。

一期使用实际有意义的物理分母，并同时报告绝对值：相对初角的实际开角/相对初角的登记目标开角（同时报绝对角及误差）、每轴RMSE/实际允许关节范围、实机耗时/相同桌面参考仿真耗时、夹口全宽与把手尺寸、成功数/总尝试数。把手行程可以用铰链到把手半径乘弧度角表示，便于说明几何规模。反馈年龄与命令周期另报分位数和超时次数。

新几何、方向、目标角及容差在正式尝试前登记。传感器或测量方法无法支持的真实门力保持NA，不能用夹爪设定力、电流或仿真力来替换。改变目标/几何/方法后另列结果，避免降低分母造成“同任务改善”的错觉。

旧原标准的0.90论文参照/0.88项目接近带仍属原归一化回报协议；不同任务、观测和方法不直接共用这一分母。当前原标准、RefXY2合格双侧回报均NA，NA不等于0，不能计算与0.88相差0.88。桌面开门角比例也不等于论文回报。
