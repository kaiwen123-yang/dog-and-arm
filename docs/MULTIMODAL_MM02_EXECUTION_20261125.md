# MM-02：全身在轨纠正与多模态模型式轨迹学习

登记日期：2026-11-25，北京时间。审查父提交：[2755fdef](https://github.com/kaiwen123-yang/dog-and-arm/commit/2755fdefc2802719fb07661f3ced7b8db63d7d8b)。本文件是下一执行轮计划，当前尚未执行新训练或仿真。方法身份为 M1Piper-Multimodal-DAggerWM-v2；两个主分支为 supervised_aggregate 与 model_trajectory。原 MM-01、standard-v1、RefXY2 的结果保持各自身份。

## 1. 本轮要交什么

从同一全机初态连续运行，学生每20 ms仅凭腕部RGB-D、语言、本体历史、上次实际动作及因果时标，自主完成驶近、停稳、到把手、抓持、按指令开门、保持、释放、撤臂、释放后保持、收臂、底盘退出和最终停稳。首先争取第一个新学生完整成功视频；同时用成对实验判断加入世界模型多步优化是否改善这一能力。

本轮必须贯通：状态化全身教师查询和新数据格式 → 真实学生在轨采集 → 四轮数据聚合/训练 → 两支从frame0物理评测 → 视频、预算和恢复包。一次旧轨迹误差下降、一次J2补丁或只有新接口代码不构成本轮完成。

桌面固定Piper部署由用户择时，当前只做仿真。原官方迁移与RefXY2封存，旧D/C/seed/H及0.90/0.88不作为本轮启动条件。本轮是自研方法；DAgger、教师轨迹监督及新目标不称为官方SuperMimic原样流程。

## 2. 为什么这样接续

MM-01正式学生24案均未接触门；23案止于驶近、1案止于停稳，首次失败合计12次自碰、5次J2越限、7次J5越限。旧3,255行学生状态上的六臂归位补训虽然降低离线误差，新闭环四案的同钟J2误差却全部升高，额外8案仍无完整成功。

当前Actor含由教师数据拟合后固定的逐通道本体仿射支路。J2物理增益约1.00002，局部输出随本体变化约0.998；这是未回正的一项机制线索，尚非唯一原因。当前H32只有0.64 s窗口，奖励主要看门角、把手距离和双指/释放，未直接表达完整12事件；想象起点又来自有标签的教师BC行，学生失败数据进入WM不等于进入Actor纠正优化。

本轮使用 DAgger 式迭代数据聚合：让当前学生决定访问分布，再在这些状态上查询专家并训练。其一般方法来源为 Ross、Gordon、Bagnell，AISTATS 2011，[原论文](https://proceedings.mlr.press/v15/ross11a.html)。本文的P6教师、机器人接口、采集比例、预算与H32目标是本项目具体设计，并非论文给出的参数。

## 4. A包：把P6变成可持续查询的全身纠正教师

从 scripts/p6_single_door.py 的真实控制循环提取 P6CorrectionTeacher，而非把 HeldTeacher.select 当作反馈控制器。HeldTeacher只负责采样保持，不会独立根据学生状态生成纠正。

1. 在每个真实frame0初始化固定home、夹口初宽、leg_rest、任务目标、IK种子、积分器和阶段状态。不能在漂移快照处重新调用Arm/BaseDrive构造器，把漂移姿态认作归位目标。
2. 教师持续观察学生实际积分的后继。保留原基座/控制状态2 ms、Arm 10 ms更新语义，20 ms仅抽取整组pre-bias目标。原BaseDrive内部用model.opt.timestep积分；仅每20 ms调用原函数会少推进十倍。
3. 教师自己的phase、计时、上一命令、IK与积分状态随真实事件推进。P6 pregrasp/approach_arm与独立裁判reach_handle分开映射，不能用旧演示帧号或裁判字符串直接代替。
4. 查询不改变正在执行的学生动作、物理状态、时钟或求解缓存。若需暂存控制量，隔离教师scratch数据，保留实际执行者记录。
5. 用名义双侧×两目标四个纯教师回合核对提取接口，比较原P6持有20 ms命令语义、全部12事件和动作映射。原实现作为对照；发现具体适配错误在同轮修正，保留失败尝试。不扩展成新的长期教师复现关卡。

学生与教师在训练混合控制时都持续更新各自历史/控制状态。教师不是部署组件。

## 5. B包：独立记录专家标签与实际物理转移

新schema至少包含：

| 字段 | 含义与用途 |
| --- | --- |
| student_action_raw | 当拍学生原始请求，含教师执行块内的学生查询 |
| expert_action_raw / expert_action_target | 同一状态上的教师请求及23路有效物理/归一化目标，供BC |
| expert_label_valid / reason | 当拍或逐通道标签资格，有限值、限位、IK/控制状态等明确理由 |
| executed_action_raw / executed_action_clipped | 实际进入伺服的请求/限幅动作，供WM与下一拍历史 |
| execution_source / intervention | student或teacher；训练混合选择与实际控制来源 |
| physical_target / applied_ctrl | pre-bias目标与每2 ms实际伺服输入 |
| parent_episode / anchor_tick / source_policy | 分叉/轮次/策略来源，防止拼接或重复计数 |
| teacher_state / judge_events | 两套独立控制/评价状态；只供教师恢复、训练标签与分析 |
| observation_times / history_prefix | 因果图像、相机相位、当前/历史观测与实际动作；分叉不假装reset |
| valid_transition / terminal / first_failure | 真实子步和首次失败边界，尾部不足20 ms单独标记 |

现有EpisodeWriter会把监督mask与整回合success相与，EpisodeDataset又把action_clipped直接当BC目标。新增schema必须分离这两个语义，旧schema保持兼容：

- BC读取有效专家纠正标签。学生后来失败，不自动删除之前合格的教师查询。
- WM读取实际执行动作和它产生的后继；未执行的教师动作绝不能配到学生后继。
- previous_action始终来自实际执行动作，包括教师执行的训练块。
- 专家查询“有资格”不等于经物理证明成功。独立保存IK/饱和/不可恢复状态以及真实恢复分支的结果；无效标签mask，不能全标有效。
- 学生首次失败即封存这一回合的评分。失败后的救援另开训练身份，不能继续累计成学生完整成功。
- 分叉保存真实前9拍历史、上一动作、实际elapsed与曝光相位；Dataset不能把分叉首状态重复10次冒充原历史。

新增采集以训练场景为来源。原MM-01的验证、测试以及本轮验证/盲测均不进入BC、WM、bridge或训练H32目标。

## 6. C包：一次短直连对照，然后进入四轮主实验

### 6.1 初始纠正数据与短对照

从AutoDL完整12,000步共同父包恢复，包括原优化器/统计，不从只有部署参数的文件声称完整续训。精确父路径从原manifest、actor/common_configuration与训练账本确认，记录实际解析路径。

先在三个原训练场景×双侧×两目标运行12个纯学生回合，全程查询23路教师纠正。保留全部实际终止。这一pool与旧17个训练来源组成初始共同数据。

仅做一次fixed/adaptive配对，每支512更新、batch256（128旧示范＋128初始新纠正，按主段场景/任务规则均衡）、相同初始函数/原AdamW状态/样本顺序：

- fixed：保留原固定servo_slope。
- adaptive：仅将23个servo_slope由buffer迁为参数，初值不变；单独AdamW组，lr=1e-4、weight_decay=0，不同时增加bias或改归一化。旧网络lr=1e-4，两支冻结原视觉/文本编码器。新参数梯度与旧网络分别裁剪/记账，避免无意改变旧组裁剪语义。
- 训练包与部署包显式保存affine_mode。loader先建立对应buffer/Parameter，再按参数名迁移原AdamW和新参数组；不能直接用旧buffer版load_actor把adaptive悄悄恢复为fixed。旧MM-01 schema保持可读。初始两支raw/clip/物理动作应一致，所有差异及新增参数状态明确存档。
- 各评8个开发回合：tr_nominal、va_pose，双侧×两目标。只在完整成功更多，或成功相同且顺序事件总数更多且越限/自碰总数不增加时采用adaptive；否则采用fixed。差异只有离线MSE或毫米级末点变化不触发采用。
- 选择的是共同结构和一个共同父节点，两条主链都复制该节点。没有明显收益仍按fixed继续，短对照不是主实验放行门，也不再增加第三条结构长期链。

### 6.2 四次完整数据聚合

每轮两支各自在3训练场景×双侧×两目标运行：

- 12个纯学生回合；
- 12个训练混合回合。

即每轮48个训练回合，四轮192个。两支的全部合格数据取并集，双方获得相同训练数据；按策略、场景、方向、目标、行为来源和轮次记账。下一轮使用更新后的学生重新采集，不能一直复用原3,255行。

训练混合在每200 ms块选择一次整组动作的执行者，四轮教师选择概率为0.75、0.50、0.25、0.10。同一任务两支使用同一预登记随机序列，实际介入比例另报。块内仍每20 ms重新查询所选执行者并输出完整23路动作，物理仍2 ms。不能把同一动作保持200 ms、按关节拼教师/学生，或不登记就做动作平均。提前终止保留自然长度，不重跑凑等长。

两支每轮各完成：

1. 2,048次纠正BC，batch256、lr=1e-4，显式将当前多模态编码器requires_grad重新置True，实际更新编码器，不能继承pilot或上一轮冻结标志。
2. 随后512次匹配BC续训；这段两支将各自编码器requires_grad置False。监督支仍只用BC，模型支加入第7节H32目标。
3. BC行序完全相同。每批128条旧合格示范、128条当前累计的新纠正/实际教师恢复标签；各池内先均衡任务/场景和行为来源，再抽回合/行，记录阶段覆盖。某池实际缺失时显式回退到另一合格池并记录，不能填造标签。
4. 原动作四组Huber和训练统计保持；不每轮重新fit_scalers改变函数。WM物理统计也从已发布包恢复固定，新增数据在原单位下训练。记录超出归一化裁剪范围比例，具体映射错误再最小修复。
5. 第一轮两支逐张量同父；后续各自连续继承权重与优化器，不丢弃上一轮H32成果。后续只有数据、监督批序和更新预算匹配，不能再声称每轮相同父权重。

每轮结束，各支从frame0评tr_nominal/va_pose双侧两目标，共16个开发案；四轮64个。必须报告各个顺序事件、限位/自碰、驻车、触门和双指，而不只记录最终成功。

## 7. D包：实际教师恢复分叉与H32多步目标

### 7.1 真实恢复短轨迹

每轮最多256个去重训练锚点，从本轮真实学生访问状态及混合回合中确实经历学生动作的状态取样；平衡方向/目标/场景，按已出现的阶段分层。缺少后半程状态如实记空，不复制旧片段或传送机器人去凑阶段。

从每个锚点的完整可恢复快照运行教师32个20 ms决策拍。保存MuJoCo状态/时间、必要求解与伺服缓存、实际历史/相机相位、教师phase/积分/IK/上一命令、控制目标与真实后继。分叉在独立物理对象中执行，不污染学生主回合。用少量同状态同动作恢复对照确认能重建这一接口，按实际误差报告，不另开跨引擎大审计。

同时每轮最多32个独立开发验证锚点，只从va_pose的真实学生轨迹取得，任何训练模块均不得抽它们。训练/验证每轮分别最多8,192/1,024个完整物理控制区间；四轮最多1,152条短分支、368,640个2 ms子步。实际提前终止、重复抽样和有效H32窗数量单列。

教师分叉产生的合格BC标签和实际转移全部提供给两支。教师未来后继是监督target，不是模型自行滚出的伪真值。不足32拍的真实分支保留有效BC/WM数据，不能补齐H32目标。

### 7.2 世界模型与桥接更新

每轮WM续训1,000个H7批、batch128、lr=1e-3，继承原物理损失及固定单位，从旧训练集和两支共同新增的实际转移训练。学生执行的失败前转移与教师实际执行的恢复转移都按真实动作使用。实际终止区间沿用合法窗规则，不跨episode拼接。

模型支完成当轮2,048 BC后冻结其当前编码器，再用训练集独立实际曝光拟合600个batch256的VisualBridge批。绑定该编码器版本及WM单位，保存确切配置/优化器和模型来源。旧bridge绑定MM-01旧编码器，不能在编码器已变化后直接使用。后续512策略批中WM、bridge和编码器固定，但梯度穿过模型后继传回策略。

用教师真实动作的H1/H7/H32开环预测与学生想象闭环分别评分；学生在轨、教师恢复、原成功验证集分别报告。视觉预测与保持起帧对照只在相同真实曝光拍比较，避免sample-and-hold时钟混淆。

### 7.3 模型式轨迹模仿目标

H32起点独立抽取本轮有完整真实恢复轨迹的训练锚点，batch32，不再从普通BC batch截取前32行。起点只用实际传感观测估计状态；每拍学生重查动作，WM推进本体、对象/接触和视觉，后续历史使用该想象实际动作。预测视觉沿相机相位更新。不能读取教师未来图像、动作、真值对象或phase作为想象Actor输入。

将预测后继与同锚点、同指令、同钟的真实教师纠正后继比较。继承现physical_loss的单位及相对权重：

| 目标组 | 多步损失 |
| --- | --- |
| 23路位置 | Huber，除以0.25×p_scale的位置部分 |
| 23路速度 | 0.6×Huber，除以相应p_scale |
| 重力/角速度 | 0.3×Huber，除以相应p_scale |
| 门角/门速/TCP系把手 | Huber，除以o_scale |
| 两指与同时双指 | 0.3×BCE，沿用真实子步接触定义 |
| 视觉特征 | 仅真实曝光拍的Huber，除以v_scale，按有效曝光数归一化 |

物理/接触项在32拍按gamma=0.985归一化平均，视觉项单独按有效曝光归一化；总目标为原BC损失＋0.15×多步损失。去掉对Actor无动作梯度的初态估计项。本轮不同时引入新的阶段奖励、风险头、关节硬锁或额外限位barrier，机械限位与自碰由原裁判实测。

这是“同数据监督 vs 加入WM多步轨迹模仿”的比较；不是原到角reward的无改动续训。保存首批各组损失/梯度、一次冻结方向导数对照和真实对应短轨迹。数值非有限或明确索引/单位错误须修复，但离线误差高、BC尚无完整成功不成为暂停H32的新门。若一个合法H32训练锚点都没有，继续有效BC/WM，明确H32未执行和实际原因，不能伪造完成数。

## 8. 场景、选择与最终评价

旧3个训练场景保持；va_pose用于开发。已揭晓te_combination只作固定回归，不能再称新方法盲测。另在训练前锁定两个新组合场景，详见机器登记；对两场景双侧两目标进行8个教师可行性回合，数据完全隔离于训练。即使教师失败也保留原案例与可行性标记，不按学生表现换场景或减少分母。

四轮或条件延长完成后，选择固定的终末节点作为主比较，不用盲测选最佳：

| 末点评价 | 每支案例 |
| --- | ---: |
| tr_nominal，双侧×两目标 | 4 |
| va_pose，双侧×两目标 | 4 |
| 旧te_combination，已揭晓回归 | 4 |
| 两个新盲场景，双侧×两目标 | 8 |
| 合计 | 20 |

两支共40个末点正式案，其中16个为新盲场景。两支均冻结、延长决定结束后才开新盲测。中间节点的开发成功可立即交视频并独立报告，不能替换主比较末点。

同初态15°/25°成对报告目标达成、最终门角、两条实际开角差、全任务成功和所有失败。动作输出有微小差别不等于理解指令。完整成功率报分子/分母和百分点差；零成功基线不计算相对提升倍数。
