## 3. 为什么暂时不能给出“离论文还差多少分”

u500 十片段共同 effort 均值是 0.22961 / 0.25963；canonical u350 一个释放撤臂片段为 0.97191，但撤臂未通过。它们都不是从完整初态连续执行双侧任务的回报。因此不能用 0.90 减片段均值来量化整体差距，也不能凭 0.97191 宣称达到论文。

论文 0.90 是 SONIC 参照线，0.88 是本项目预登记 0.02 容差；对象交互任务与原 G1 benchmark 不同。WM 的 TCP 毫米误差、M1/Piper 加权状态 loss 与论文图3误差也不能直接相减。共享 GPU 上 0.665 小时训练墙钟，不等于论文独占 H100 三小时的等效预算。[指标定义](B0_PAPER_BASELINE_PROTOCOL.md)

## 4. 下一轮首先需要改变什么

已对齐机制不再重做。最完整配置只训练到 u50，旧单位配对才到 u500。当前首要工作是把标准采集、数据与学习连接起来：

1. 对齐终止后各 lane 重新采集的生命周期，正确维护真实前缀、history 和 episode 边界。
2. 补足两侧接触模式的真实状态—动作数据，用原 H1/H7 损失预热 WM。
3. 单一标准配方实际联合学习，以持续双指、受控门力、阶段事件和正式通过为依据继续训练。

固定统计 replay 的 H7 15,707 窗 open/hold 为0；Actor起点24,812中仅572为open/hold。力可观察样本的首20ms持续双指为0，但未标注样本未知。逐lane复位增加机会，并不自动解决首命令超力或产生接触长窗。[覆盖核验](../results/b0/pair_sampling_audit_v1/replay_draw_grip_fixed_stats_u50.json)

## 5. 与长期腿臂协同目标的关系

完成当前标准迁移后，保留独立基线及固定协议，再进入视觉/语言、本体历史融合、部分可观测 WM、联合学习和实机适配。当前相机资产、Piper/DC1 H0联调和仿真平台可继承，但它们不等于最终语言条件整机开门已经完成。[长期路线](RESEARCH_ROADMAP.md)

本轮只发布审查与下一步，没有启动这些后续研发。方法改动先后分开，才能使未来比较清楚回答：提升来自完成了迁移，还是来自新增算法。
