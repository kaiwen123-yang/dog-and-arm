# 距离标准迁移与腿臂协同最终目标还有多少

日期：2026-11-23，北京时间。最新实验证据为 [638fddc](https://github.com/kaiwen123-yang/dog-and-arm/commit/638fddcb2f025006595f79f27a977a8fba41cbc2)。当前用户目标明确为：详细研究开源SuperMimic，先迁移到M1＋Piper H，达到或接近论文指标，单独形成后续比较基线；完成这一阶段再做新开发、多模态/VLA。本次只研究、审查和发布下一计划，无新训练或物理/硬件执行。

## 1. 当前处在什么位置

**已经完成工程平台和B0-03无接触学习；标准方法仍卡在B0-04接触，尚未形成可以宣称达到论文指标的标准候选。** 最新五条seed0配置末点的正式接触均0/10，gain32到H32-u200后Warp/native仍各0/10。混合参考策略已有完整单门名义能力，但不能填入标准方法的结果。

独立结果已经建档：[B0_STANDARD_TRANSFER_BASELINE.md](../reports/B0_STANDARD_TRANSFER_BASELINE.md)及[manifest](../results/b0/standard_baseline_20261123/baseline_manifest.json)。这解决“结果单独保留、以后能够比较”的组织问题；它没有把尚未发生的实验成功补出来。方法ID为SuperMimic-M1Piper-standard-v1，目前最终candidate为空。

0.88是本项目事先规定的0.02工程容差，不是原论文定义；0.90也不是SuperMimic最佳成绩。最终每seed、每侧、每split单列，并同时过原物理门槛。原论文训练动作覆盖和本项目H未见条件分别报告。详见[独立指标协议](B0_PAPER_BASELINE_PROTOCOL.md)。

单步后继tracking的0.09080/0.1看似90.8%，对应动作却在首2 ms产生30.64 N>6 N；这是失败后仍继续积分的诊断，不能算成完整回报0.908，更不能说“已经接近论文”。[本轮审查§7](../reports/B0_STANDARD_ROUND_REVIEW_20261123.md#7-高-tracking-与接触失败可以同时发生)

## 4. 这一轮仍有哪些实质进展

本轮从标准锚点进行了五条有明确身份的配对训练。新增合计400 H32、4,000 WM、8,000 Critic、657,570有效转移，剔除了续训前缀重复。动作scale×32在初始物理动作和探索不变条件下比较，修复归一化尾槽伪信号，补了独立验证与握持训练数据，确认WM统计变化可以改变原有函数。415条评分和失败完整保留。[实验审查](../reports/B0_STANDARD_ROUND_REVIEW_20261123.md)

最新审查进一步定位到：官方动作平滑惩罚在effort前网络坐标，项目却用canonical物理范围坐标；相同J2物理跳变的惩罚约弱3,948倍。接触采集还没有接入ReturnSampler，replay_ratio16没有实际影响当前固定cohort调度，前瞻尾部也不同于官方夹取末帧。这些是具体实现差异，优先开展匹配学习；尚不能说任一差异已经被证明是全部失败根因。[官方代码研究](B0_OFFICIAL_IMPLEMENTATION_AUDIT_20261123.md)

WM仍有明确不足：同双指H32窗口，held_r2的TCP P95为50.53/40.36 mm；wmcoords-u50为100.66/82.60，gain32-u200为551.98/278.53，简单常速仅13.95/11.86。部分改动改善相对退化，但还未建立可靠接触预测与真实控制收益。前拉412窗/51 lanes、背推450窗/56 lanes，不能把重叠窗当独立试验。[独立结果§4](../reports/B0_STANDARD_TRANSFER_BASELINE.md#4-世界模型和真实接触的解释证据)

下一轮应针对这些证据先对齐原有动作率公式的单位，做实际配对训练，再落实采样/调度和WM覆盖；有进展后继续有效训练预算，沿接触→完整任务推进。[执行计划](B0_STANDARD_TRANSFER_PLAN_20261123.md)
