## 1. 这一阶段要让用户看到什么

M1 从门前一小段距离外驶入操作位置，停稳；Piper H 伸向把手、夹住、把门拉到约 60°；松爪并退开，整机仍由轮腿稳定承重。整个过程在同一场景、同一物理状态中连续发生。底盘在抓门时可以驻停，但它始终是自由基座，开门反力由机器人和轮地接触共同承担。

先完成前侧拉门，再修正并接入背侧推门。前拉已有较干净的双指接触基线；背推的 25.076° 样本包含夹爪基座碰把手，不能直接作为双指抓持质量达标的样本。

当前继续使用已知门结构和 MuJoCo 状态真值，解决运动与接触衔接。腕相机保留观察用途；不是视觉闭环。手眼、标定板、附件称重/惯量继续后置，附件和名义安装座额外载荷仍 omitted。H0 不重做，本阶段不操作实机。

| 现有内容 | P6 的用法 |
| --- | --- |

| P4 前拉圆弧、腕部朝向和退离形状 | 作为操作参考几何；由当前门角和实际底盘姿态重新生成可执行目标 |
| P4 六轴 IK | 在独立 scratch data 中求解，每次先同步物理根和非臂关节状态 |
| P4 臂/爪有限执行器 | 只负责臂/爪通道，不能覆盖腿轮控制 |
| 现有 CSV、summary、视频和曲线习惯 | 保留并增加任务事件、实际命令、分接触力和持续停车判据 |

必须处理的具体问题：

1. **一场连续仿真。** 现有 P4 `build()` 会删除自由根，`run()` 会新建并重新初始化 `MjData`。不能先跑 P5，再调用这两个入口。P6 自己拥有一个物理 `MjModel/MjData`，只在每次独立试验开始时初始化一次；接近、停车、伸臂、开门之间只更换控制目标。
2. **执行器只有一个最终写入处。** P4 会配置所有 23 个 actuator，并每步覆盖整个 `ctrl`。P6 应将 12 个腿关节、4 个轮、6 个臂关节、1 个夹爪输入明确分组。控制函数返回各组命令，由主循环合并后写入并 `mj_step`。不得让两个既有 `run()` 抢写。
3. **轮速计算使用车体系。** P5 当前使用世界轮轴 Y 分量和绝对世界轮心 Y；在原点、yaw=0 的初态成立，在 P4 的 45°/90°站位不成立。改为相对基座的轮心位置和轮轴方向，明确半径、符号、速度/角速度的坐标系。用平移后的 45°初态和已有正负转向做少量有针对性的验证；不要另建测试框架。
4. **IK 使用实际底盘姿态。** P5 停稳根高约 0.531984 m，比 P4 固定根 0.54266 m 低约 10.68 mm。即使没有水平漂移，也不能沿用固定根关节表。目标可以在世界系表达，但求解必须看到实际根的平移、四元数及腿姿态。目标变化应限速，避免每次在线求解跳到另一支解。
5. **统一抓取点。** P4 的 `p4_grasp` 位于夹爪主体局部 `[0,0,0.115] m`，不是名义 TCP 的 0.138 m。沿用这个已验证操作点并明确命名，不能在重构时引入 23 mm 偏差。腕部 optical frame 是另一用途。
6. **把“计时结束”改成“条件满足”。** 现有 P4/P5 多数阶段按时间转换。P6 的停稳、抓稳、门角完成和释放完成应由状态判定；时长只做平滑参数、最小等待和明示的仿真阶段上限。

## 3. 四个有意义的调试节点

### P6-A：自由底盘在操作站位承重，机械臂展开

先在门前操作区初始化一次自由根，作为隔离诊断，不把它称为“自主接近”。沿用前拉站位的平面位置 `[0.65,0.30] m`、yaw=45°作为首个候选；根高先由真实轮地接触沉降，不能把根锁在 P4 高度。

完成统一场景、执行器分组和车体系轮速分配。先让臂处于行驶姿态，停稳后平滑移动到预抓取位，再做覆盖前拉工作空间的无接触慢速臂运动。根据实际根位姿做 IK、关节限位和几何检查；保留完整门/底盘/夹爪碰撞。

驻停行为至少包括零轮速制动、可重新纠偏的航向保持和小范围前后位置修正。P5 的一次性 `heading_stopped` latch 不能代替驻停抗扰。固定轮轴不能像全向底盘一样直接执行独立横向速度；横向误差超出工作区时，在夹持前调整接近路线。接近/停车阶段允许正常航向修正；夹持阶段降低纠偏速度上限，必要时先暂停开门进度再纠偏，避免独立的航向环与抓持环互相施力。

**用户画面：** 一扇关闭的门、四轮承重的整机，机械臂慢慢展开；显示底盘漂移、倾角和四轮法向力。输出本节点实际表现及是否可以进入接触。

### P6-B：先小角度，再完成约 60°自由底盘拉门

在每次试验内部保持同一个自由底盘物理状态，按“预抓取—接近—夹持确认—小角度拉门—松爪—退离”完成首次 10–20°试验。确认开门反力下没有持续滑移、失夹、非预期碰撞和明显控制饱和，再扩大到约 60°。小角度与60°可以是不同独立试验，各自使用新run_id并在开头初始化一次。小角度是定位耦合问题的中间节点，不是 P6 的最终结果。

操作目标根据当前基座位姿和门角更新。先复用有限关节伺服；只有实际跟踪或接触力问题需要时，再增加有限、可解释的末端柔顺或小步重规划。不要同时提高底盘与手臂刚度来硬顶几何误差。

门角进度需要一个明确的推进量。可以让参考角在抓持稳定时按受限速率前进，同时限制它领先实际门角的幅度；发生夹持变差、末端误差或持续饱和时暂停推进。仅把手部目标设为“当前实测把手位置”而没有推进量，无法主动开门。也不能让预定时间轨迹在失夹后继续走完并报告成功。

先沿用已验证的绕竖直把手调整腕部朝向方案。抓持质量指标应允许计划中的绕把手轴转动，不能把这种有意转动与平移滑脱混为一谈。

**用户画面：** 底盘没有固定约束，但四轮仍承重；夹指拉动被动门，门角随接触变化。近景能够分辨两指、把手、夹爪基座；结束后继续物理步进观察释放后的门与底盘，再保存并停留画面。

### P6-C：接入短距离接近，完成第一次连续任务

从操作点后方约 0.30 m 开始，先选一条简单、可见、避开门板扫掠区的接近路径。若沿 45°车头向前接近上述候选站位，初始平面位置示例约 `[0.438,0.088] m`；这只是待做几何检查的场景候选，不是已经验证的可行位置。

机器人从行驶臂姿出发，以不高于现有 0.07 m/s 基准的低速驶入，逐渐减速。停稳并且位姿落入机械臂可达工作区后，才伸臂抓门。停车点的厘米级误差由当前状态下的 IK 和任务目标处理；不能在抵达后重置到 P4 站位。

开门、释放、机械臂退离后，先回到合适的收臂姿态，再沿已检查路径退离门扇扫掠区并停车。本段底盘退离与 P4 机械臂退离不同，须单独保留路径和碰撞证据。

**本节点完整完成条件：** 同一物理时间线上有接近、停稳、双指接触、约 60°开门、释放、臂/底盘退离、最终稳定；自由根始终保留，没有状态重置、门电机或把手焊接。

### P6-D：小范围条件变化与背侧推门

先对已通过的前拉整任务做预先列明的小规模条件变化，再清理背推接触方式并接入同一控制接口。若任务定义仍是双指夹持，夹爪基座顶把手须判为接触质量未通过，不能只看门角。

背推初期沿用约 25°目标，解决抓持和退离后再决定更大角度。它不必在第一次自由底盘前拉之前完成。自由单门两侧流程都清楚后，再进入 P7 双门；此时仍不要求先训练 RL、做完整全身 MPC、接入视觉或穿过门洞。

| `reports/P6_FREE_BASE_DOOR.md` | 每个真实节点的事实、失败原因、视频和下一步 |
| `results/p6/<run_id>/` | 独立试验的配置快照、时序、事件、汇总和短视频 |

只在确有两处复用时抽出小型公共控制函数，不先建立通用机器人框架。主循环组织如下：

1. 读取当前根、关节、门、把手和接触状态，全部明确坐标系。
2. 状态机给出基础速度/驻停参考、末端参考、夹爪宽度和允许的接触集合。
3. 底盘控制产生腿/轮指令；臂控制同步 scratch state、求解或更新 IK，产生臂/爪指令。
4. 同一处合并受限 actuator 命令，推进 `mj_step`。
5. 记录真实状态和有效命令，更新事件条件与可视化。

初版可继续用 0.002 s 物理步长，臂任务更新约 100 Hz，viewer 约 25–30 Hz；这些是复用既有频率的起点。记录实际 wall/sim 实时比，不能把显示刷新频率当控制频率。在线 IK 计算过慢时先用连续种子、减少不必要重算和现有几何，不靠跳过动力学或提高步长掩盖。

状态机至少区分 `approach_base / settle / pregrasp / grasp / open / hold / release / retreat_arm / post_release_hold / retreat_base / final / failed`。每次切换写明事件和当时数值。失败后停止任务推进、保存现场和失败原因，可暂停物理供查看；暂停画面不算稳定性验证。名义试验不给自由根或门添加外力。将来如果专门做扰动试验，应另标扰动输入，不计为辅助开门成功。

## 5. 开跑前声明的初始工程门槛

以下是**待实现、待验证的工程参数建议**，不是论文标准、实机额定能力或既有测试通过项。首轮采用后应记录到配置；需要调整时先解释原因，保留原运行结果，不能事后放宽成功定义。

| 项目 | 初始建议 | 说明 |
| --- | --- | --- |
| 接近停稳 | 水平速度 <5 mm/s、世界系偏航速率 <0.5°/s，持续至少 1 s | 用连续采样窗口；现有无门 P5 park 速度 P95约1.24 mm/s，仅作选值参考 |
| 抵达操作区 | 平面目标误差 ≤2 cm、航向误差 ≤2°，且当前姿态可达 | 位置门槛不能替代 IK 和碰撞检查 |
| 抓持确认 | 两指均有有效把手接触持续 ≥0.2 s，并检查实际开口/把手相对位置 | 不以“已发闭爪命令”代替抓稳；接触检测阈值单独记录 |
| 抓持中基座 | 世界XY平面相对操作停稳参考漂移 ≤2 cm、偏航 ≤2°；横滚/俯仰各 <5° | 根高另行记录；同时监测变化趋势 |
| 抓持平移误差 | 抓取点相对实际把手的非预期平移 ≤5 mm | 排除有意绕圆柱轴转动；参考与坐标系必须定义 |
| 目标开角 | 初试10–20°，正式60°；预先声明最终允许误差 ±2° | 60°容差不追溯改写 P4 严格阈值字段 |
| 释放后 | 松爪且臂退到无接触位置后，进入 `post_release_hold`，目标门角容差和底盘稳定条件维持 ≥3 s物理时间 | 底盘仍按操作停稳参考保持；此后才开始底盘退离 |
| 支撑/碰撞 | 无非轮着地、机器人自碰撞、门板/门框/夹爪基座非预期接触；无持续抬轮 | 记录接触阈值及抬轮持续时间，短数值瞬态与持续失稳分开 |
| 执行器 | 记录限幅及饱和持续时间；持续饱和时暂停推进并诊断 | 已配置力矩上限不等于末端力限制 |

接触力上限暂不从 P4 的“范数之和”猜一个净力数值。先在小角度阶段正确记录接触向量和任务接触质量，再结合实际载荷设定并固定下一阶段的名义实验阈值。所有控制限幅仍沿用已明确配置的 actuator 上限。

抓持平移误差定义为实际把手坐标系H中的抓取点位置，与允许绕轴转动下参考位置之差：`e_grip = norm(p_H_grasp_actual - p_H_grasp_reference(alpha_planned))`。若抓取点设计在把手轴线上，参考平移可以不随绕轴角变化；否则必须随计划转角计算，不能简单减掉初始相对位置。这个量检查实际抓持几何，与“有效进给目标—实际末端”的伺服误差分开记录。

操作停稳参考只用于伸臂、抓持、松爪及 `post_release_hold`。进入 `retreat_base` 后，按已声明的退离路径和终点判断跟踪，不再用离开操作点的距离判漂移。抵达最终停车点后，重新建立相对该停车目标的稳定窗口，至少3 s物理时间同时满足速度、姿态和门角条件，才记完整P6成功。中间的3 s释放后保持不能替代这个最终窗口。

首跑配置还须列明有效接触法向力阈值、失夹持续时长、抬轮判断阈值/持续时长，以及实际 `actuator_force` 相对各自上限的饱和比例和持续时间；它们在启动前确定并写入配置快照。`ctrl`到边界与实际执行器输出达到力上限是不同事件。

## 6. 记录应能回答的问题

### 机器人是靠自己承重和抵抗门力吗？

记录根位置/四元数、明确世界或车体系的线/角速度、根高、四轮法向力、轮地滑速纵/横分量、腿轮臂/爪实际输出，以及各通道命令和饱和持续时间。轮地侧滑按转弯、停车、抓门分别统计，不用转弯峰值替代接触阶段状态。

### 是夹指在操作门，还是别的部件在顶？

逐接触记录双方 geom、位置、穿透、力和力矩。`mj_contactForce` 返回接触局部坐标系六维量，应按该接触 frame 转到世界系并核对受力对象符号。分别汇总手端所受门接触力、关于指定基座原点的门接触 wrench；加上力臂叉积，明确参考点。它是**门对机器人接触的等效 wrench**，不是包括重力、地面反力和惯性项在内的整机净受力。

保留旧的力范数之和用于对照，同时输出双指–把手、夹爪基座–把手、机器人–门板/门框、自碰撞的独立类别。现有 P4 CSV 无法事后恢复这些逐时向量，不能把历史峰值当成已测得的六维负载回放。

### 目标、控制命令和真实状态分别是什么？

同时保存原始任务参考、反馈修正后的有效末端参考、实际抓取点位姿、当前把手位姿、实际夹爪开口和门角。P4 推门旧 `tcp_error_m` 相对未修正轨迹，不能继续混用为 P6 的控制跟踪误差。

`summary.json` 应含目标、容差、保持时长、每项通过与否、任务结束原因、实际帧/步数和数据来源。`script_completed` 与 `task_success` 分列；没有执行的阶段保持未完成。汇总峰值在物理步统计，CSV采样率明确；失败试验也保留结果。

## 7. 条件变化：用少量不同案例检验适用范围

名义整任务在桌面完成后，冻结该配置，再执行下面20个小范围案例。所有位移都是**机器人初态的世界X/Y偏移**，航向为相对名义初始yaw；门位置、操作目标和接近终点保持不动。只有明确列出的门初角改变门状态，正式目标始终是**绝对门角60°**，不是在初角上再增加60°。未列参数均等于冻结的名义配置。

| case_id | 相对名义配置的改变 |
| --- | --- |
| C01 | 无，名义完整任务 |
| C02 / C03 | 机器人初始X：+0.05 / −0.05 m |
| C04 / C05 | 机器人初始Y：+0.05 / −0.05 m |
