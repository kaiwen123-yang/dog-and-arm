## 4. 04-A：把接触任务的数据和执行接口闭合

### 4.1 具体改动位置

以 `learning/b0/` 的表示、数据、物理、奖励、训练代码和 `scripts/b0/` 的采集/评测入口为工作面。共享状态与动作 schema 由一个集成任务统一；可以扩展现有模块或拆出门任务模块，但保持已冻结无接触配置可复现。

需要解除的无接触专用假设包括：61 维机器人状态、三类等长 7 s 参考、单值 context、统一“碰门即失败”、固定任务数/参考长度以及只读取机器人运动的参考库。所有 replay 分配、normalizer、batch 索引、尾部 mask 和 checkpoint 元数据随 schema 一起更新，不能只修改网络输入维数。

### 4.2 动作与时间

- 默认保持 `physics_dt=0.002 s`、`policy_dt=0.020 s`、decimation=10；23 路动作仍是 12 腿位置＋4 轮速度＋6 臂位置＋1 总夹口宽度，按名称映射。
- 一条监督记录必须是 `s_k → a_k → s_(k+1)`：在策略边界确定动作，物理目标在后续 10 个子步保持，记录真实积分后的下一状态。固定低层伺服和已声明的逐子步偏置补偿可依实际状态更新，因此“物理目标保持”不等于“执行器 ctrl/力矩完全不变”。
- 保存 raw、clipped、physical target、实际 ctrl、实际执行力的语义与必要子步信息；不能重复 scale/offset 或重复应用夹口到单指的 1/2。
- 用门任务参考和新采真实动作逐通道核对可表达范围、输出尺度与裁剪/饱和比例。`quarter_effort_over_servo_gain` 是已通过的网络输出尺度起点，不自动保证门任务的探索与优化合适；先区分物理可达范围与网络标准动作幅度，有证据再建立尺度变体。
- 冻结奖励使用的参考时刻：例如后继状态对应 `t_(k+1)` 的目标；真实环境、WM rollout 与评测一致。参考时钟按策略步推进，不由教师根据真实门角在线纠偏。
- 每段不足 10 个子步的末尾单独保存精确时间、terminal successor 和有效标志，不填充伪造 20 ms 转移。训练窗口不跨 reset；失败之前的真实终止状态参与有效单步监督。
- 分开记录首个失败子步与 transition 的实际跨度。训练若仍可进行有限、有效的物理积分，可完成剩余子步得到真实 20 ms 终止转移，同时保留最早失败事件；若提前中止或数值故障，只保存实际部分区间并标为不适用于固定 dt 监督。独立评测可在首个失败步停止，不能把 6 ms 等部分区间冒充 20 ms，也不能拿 auto-reset 后的新初态当后继。
- 完整门参考长短不同，保留实际长度和有效 mask，不循环拼接尾帧、不在片段之间悄悄重置。需要参考结束后的保持段时，在生成参考时明确记录长度和目标。

### 4.3 必要数据补采

保留既有 500 Hz 教师门轨迹为参考源。新增教师采集器在策略边界更新物理目标并保持 20 ms，再实际积分收集接触转移；仅对旧数组隔十帧取样或取平均动作，不构成正确监督。

先获得抓持、短保持、小角度推拉、释放的有效转移，再扩充失败、滑脱、接触丢失和恢复尝试。教师的高频版本已经证明后端可行；新的 held-action 版本若失败，要区分控制更新频率导致的教师能力变化和环境/数据错误，保留失败，不用旧高频成功掩盖差异。若证据表明必须改变策略频率，建立单独变体，同时修改数据、参考、GenCoord 积分系数和评测时间，不静默改变默认基线。

按完整 episode 划分 WM 训练/验证，来自同一次完整教师执行的不同切片属于同组；独立再采的验证 episode 不进入优化器监督或 replay。若用于开发诊断、超参或检查点选择，明确它是 validation，不称未用于模型选择的独立测试；它与完整门 H 条件测试的身份分开。数据量以补齐实际接触模式和失败覆盖为依据，记录独立 episode 数，不把并行复制当新增独立数据。

继续保留已验证的数据池处理：教师长序列与在线 replay 分离；在线长序列不足时可以采教师长段，同时保留真实失败 terminal 的单步监督。每次更新记录实际来源比例，不能声称使用了在线长序列却实际上全是教师。

### 4.4 接触审计与复位

将预期的“目标侧夹指—把手”接触与机体/臂/非目标杆/门板/门框碰撞分开。接触允许范围与任务阶段必须来自冻结几何和事件规则，不能把门接触审计整体关闭。原生与 Warp 用同一事件定义；按每个 2 ms 子步计算限位、碰撞、失载、失抓与保持持续时间。

不能直接复制 P6 控制循环充当学习策略评估器。其 near/open 等条件包含教师内部 IK 误差、开门指令与 ramp 完成状态；新评估器须将这些条件明确映射为“冻结参考的期望几何/时刻＋实际 TCP/姿态/门角/接触”，逐项登记语义和差异，保留原物理门槛。在既有教师成功及真实失败记录上核对事件一致性；原数据缺字段时只补对应证据，不为满足条件偷偷运行教师 IK 或状态机。

接触分类按前拉/背推选择对应目标杆；同一并行批中的不同 world 不能共用前侧标签。原 `grip_net_force_limit_n=6` 指门对机器人合力的范数，不能用每指法向力或各接触力范数之和替换；三者分别记录。接触标签对应其求解区间，保存子步起止时间，不混称为末状态瞬时真值。连续 0.20 s、0.15 s、3 s 判据用整数物理步累计，避免 float32 仿真时钟累计误差。

训练片段 RSI 恢复机器人和门的姿态/速度、上一动作及所需真实历史。接触缓存重建过程明确记为初始化，不计为策略完成的稳定保持；必要时通过真实物理前缀建立接触。评测片段可以使用预先固定的片段初态，完整任务评测只允许规定的全程初态。

### 4.5 对齐后的短接触验证

在新采集/审计接口正式大批运行前，用同一初态及同一 50 Hz held-action 短序列比较 Warp 3.16、CPU 3.16 与原生 3.3.0 的门角、指—杆接触、相对几何、轮载和失败事件。接触轨迹不要求逐位相同；差异必须能对应到物理或接口原因。并行接触批次还要记录实际接触/约束容量溢出，不能由单世界教师通过推断 128 worlds 已无此风险。后续冻结 Actor 的迁移评测由各后端自己的当前状态闭环产生动作，不能拿另一后端的动作回放代替。

## 5. 04-B：让世界模型真正预测机器人与门

1. 门角和门角速度是动态状态；门轴、把手几何和逐 episode 固定物理参数属于 context。不能把变化的门状态放进恒定 context，也不能继续沿用 B0-03 中冻结门状态的诊断方式。
2. 门是固定于世界的独立物体，不把它当作安装在机器人根上的额外关节。由预测的根姿态和预测的门角逐步计算门轴、把手与 TCP 的相对位置/朝向。
3. 保留 GenCoord 的“速度变化预测＋解析积分＋可微几何”机制；在当前 2 ms×10 下记录实际积分系数 0.55。门状态、机器人状态、loss、reward、critic 与 rollout 时间同步；真实仿真下一门角只作监督目标。
4. 预测两个真实夹指状态或宽度＋约束残差的等价表示，不能强行清零真实接触下的耦合残差。门角、门速、米制夹口、根与关节分别设置有物理含义的归一化和损失尺度。
5. Actor 默认仍为本体历史＋事先给定参考；门真值供 WM/Critic 与独立评测。需要对象特权输入作可观测性诊断时单独命名，不覆盖默认结果。若使用接触力/标签作 WM 输入，必须定义想象阶段的更新方式，不能每步查询真实未来接触。
6. 扩展维度后可以迁移 B0-03 中形状和语义均一致的权重；逐项列出载入、新初始化及 normalizer 处理。维度改变的状态/价值层不能按位置盲装，优化器状态也不能机械复用。该过程叫迁移初始化，不叫无缝 resume。

### 模型检查与学习信号

在按 episode 留出的真实片段上，分别报告自由运动、首次接触、稳定抓持、滑动/失抓、释放的 1/7/32 步误差；对应 20/140/640 ms。至少列根、TCP、夹口、门角和门角速度，另列轮速、约束残差、有效样本分母及发散数，保留接触附近的高分位/最大误差。与保持当前状态、按当前速度外推进行同一片段比较，不要求近乎静止的所有分组都胜过几乎零误差的持位对照。

不照搬无接触 TCP 误差作为抓持成功阈值，也不凭 WM loss 下降宣布通过。结合物理失败发生位置判断模型偏差是否足以解释失败；预测误差、实际任务结果和动作梯度诊断分别报告。

Actor 更新时固定 WM 参数但保留动作到预测状态/回报的梯度，沿用官方短时 rollout 与 Actor/Critic 更新。梯度存在只证明链路连接；需要时用实际接触邻域的动作扰动做局部诊断，不能把接触切换当成全局平滑系统。

## 6. 04-C：分项学会接触

优先从对应方向完整参考中定位事件片段；机器人参考与门参考保持同一 episode 来源。下表在 5°/15° 加入 3 s 保持是新片段协议，原连续开门教师未必在这些角度停留，须补采真实保持 episode 或明确经过物理验证的参考生成规则；不能重复末帧就宣称已有可执行保持参考。第一轮按以下矩阵记录，避免一个总成功率掩盖某一方向失败。

| 子任务 | 方向/目标 | 必须观察到的结果 |
| --- | --- | --- |
| 接近并闭爪 | 前拉侧、背推侧分别统计 | 两指真实接触目标杆，满足原几何/开口条件并连续确认 0.20 s |
| 稳定抓持 | 两侧分别统计 | 预先规定的 3 s 保持；身体与抓持条件持续满足，门角在本片段目标范围 |
| 小角度前拉 | 约 5°、约 15°分别统计 | 达到对应目标，保持 3 s，失抓/碰撞/限位判据通过 |
| 小角度背推 | 约 5°、约 15°分别统计 | 同上，不能借用前拉成绩 |
| 释放、退臂与保持 | 两侧分别统计 | 真实脱离目标，退出要求区域后连续保持 3 s，机器人不再接触门 |

目标角是该片段预注册参考的门角目标，初始门角与目标角/转角的定义分别写清。采用原任务目标误差≤2°和现有抓持/失抓/身体要求；仅位置接近不能算抓持。

各子任务先 nominal，再在单独注册的接触开发集上评估 20 个有效小扰动初态，目标每项至少 18/20。开发条件独立命名为 `contact_dev`，先做初态几何有效性检查并固定生成范围/排除规则；不得拿封存的 H01–H50 调片段。nominal 与这 20 条的身份关系应明确，不重复算独立样本。

接触片段初态可以已有合法的目标指—把手接触，因此不能直接套用完整任务初态“所有非轮地接触都排除”的筛选规则。按阶段限定允许接触及重建条件；既不能筛掉所有抓持初态，也不能扩大允许碰撞范围来凑足 20 条。

先保持原 motion tracking 主奖励。确有证据需要门角进展、相对几何或接触奖励时，另建 `task_reward` 变体并保留原 tracking 结果；真实环境与 WM 同时修改，检查奖励时序、dt、单步上界和 Critic 回报截断。想象阶段的奖励只能依赖可预测量及给定参考，不能读取物理仿真的未来接触判据。

输出 `reports/B0_CONTACT_SEGMENTS.md`、逐项逐案表、成功和代表失败完整片段、分接触模式预测表、初始化与迁移说明。片段 18/20 通过不能写成从头完整开门 18/20。

## 7. B0-05：学习策略连续完成单门任务

### 执行顺序

1. 先前拉：训练和评测整条 60° 参考。从 0.30 m 外的规定任务初态开始，经过驶近、停稳、伸臂、抓持、开门、保持、释放、退臂保持、收臂、倒车、终点停车。
2. 前拉可执行后训练 95° 名义站位的 25° 背推；保持同一状态/动作/事件定义。
3. 建立两侧共同参考库，训练/微调同一套 WM/Actor，复查先学任务的遗忘。参考身份可以区分方向，不能按侧偷偷换另一组策略权重。
4. 每侧先 nominal 再 C01–C20；从完整初态一次执行到底。阶段评估器只记录事件和判据，不输出导航、IK、抓持或开门动作；每个动作来自策略，固定物理伺服除外。

固定参考时钟是默认定义。若全程累积误差使参考时序与物理事件脱节，先在开发数据上诊断；不能直接调用教师按真实门角调整参考后仍称原基线。确需事件条件/参考速度调整时作为有名称的适配，明确新增信息和控制路径。

### 沿用的完整任务门槛

| 项目 | 要求 |
| --- | --- |
| 门与身体 | 自由根、被动门、真实双指；全过程无教师接管、无中途 reset、无直接写门角或焊接把手 |
| 目标 | 前拉 60°、背推 25°；终态及规定保持段误差≤2° |
| 抓持 | 两指/几何/开口联合判据；确认 0.20 s，持续失抓 0.15 s 等阈值沿用冻结实现 |
| 两个停车窗口 | 退臂后独立连续 3 s；收臂倒车后的终点再独立连续 3 s；不能重复计同一段 |
| 停稳 | 水平速度<0.005 m/s，偏航速率绝对值<0.5°/s，及对应阶段的门角、脱离与身体条件 |
| 物理约束 | 逐 2 ms 步审计有符号限位余量、非预期接触、失稳/失载和原定义的力/滑动/饱和限制 |
| 结果完整性 | 原阶段事件顺序和物理超时保持；失败、中断、异常与缺失分开记录，不算成功 |
| 开发回归 | 同一冻结检查点，两侧 C01–C20 分别至少 18/20 |

原配置按 `p4_pull_60.yaml/p4_push.yaml → p5.yaml → p6_pull.yaml → 推门时 p6_push.yaml` 合并，具体阈值以冻结实现为准。训练用软终止不能替代完整任务硬失败；各结果保存实际解析配置。

输出 `reports/B0_FULL_TASK.md`、同一检查点的两侧完整视频、逐案 JSON/CSV、每条失败事件、原 P6 对照与策略动作来源说明。大批评测前先用代表性通过与真实失败轨迹核对新评估器事件，检查服务于具体误判风险，不建立通用测试套件。

## 8. B0-06：独立训练、留出条件与跨后端结果

### 8.1 三种数据集合分开

- 接触 `contact_dev` 与完整任务 C01–C20 属于开发/回归，可用于调参。
- WM 验证集按完整 episode 分组，用于预测误差；不能把同一 episode 的窗口数量写成独立任务数量。
- `config/b0/door_held_out.json` 的 pull/push 各 H01–H50 保留到最终冻结评测。当前只证明初态几何有效，没有学习成功成绩；文件可审阅不等于任务结果已经泄漏。

冻结代码、模型/物理参数、参考库及选择/对齐规则、Actor 输入、normalizer、训练配方、检查点选择规则和成功阈值后，再运行 H 条件。seed0/1/2 三条训练链的配方、检查点选择规则及最终候选均冻结后，才查看任一 seed 的 H 任务结果，不能先看 seed0 再据此调 seed1/2。不得为测试条件在线生成教师答案，也不根据失败换一套更容易的 H 条件。若用测试失败改方法，原测试标记为已用开发资料；新一轮需要另注册新的留出集并保留旧成绩。

### 8.2 种子与继承关系

目标为 seed0/1/2 三条独立训练链。seed0 继承当前已通过的 B0-03 再完成接触训练；配方稳定后，seed1/2 从各自网络初始化、随机数和在线采集开始，先通过同一无接触要求再进入接触/完整任务。共有的固定教师参考可以复用，但不能只克隆 seed0 权重、更换评测扰动 seed 就称三次独立训练。

如果为诊断选择共享 B0-03 权重只改变接触阶段 seed，单独标为“共同预训练、接触阶段种子”，不能替代完整链独立性目标。报告 seed0 曾参与开发选型，后续 seed 按冻结配方验证；每个 seed 的来源、计数和检查点选择规则可追溯。

| 范围 | 目标与报告方式 |
| --- | --- |
| 每训练 seed、每侧开发/回归 | C01–C20 ≥18/20，逐案保留失败 |
| 每训练 seed、每侧留出 | H01–H50 ≥40/50，列范围、条件和失败类型 |
| 统一模型 | 每个 seed 的同一个 WM/Actor 检查点支持两侧；不跨 seed/侧拼最优结果 |
| 后端对照 | 冻结策略在 Warp 3.16 与原生 3.3.0 上至少完成两侧 nominal；完整 C/H 清单按后端分表报告，未跑写未跑 |

主结果先按训练物理后端判定；只有原生后端也实际达到对应门槛，才可声称该后端通过。需要定位 3.16 Warp 与 3.3.0 差异时增加 CPU 3.16 对照，避免一开始重复所有统计却无法解释接触差异。跨后端复跑是相同条件的不同物理实现，不是新增独立测试条件。

## 9. 训练组织、诊断与持续推进

- 首次实现可并行做：动态门表示/训练适配、采集与变长参考、独立事件评估。共享 schema、模型生成与主状态由一个任务集成。依赖未完成时不启动以假字段占位的正式训练。
- 有效配置形成后，可并行采集独立开发 episode、评测已冻结检查点；单模型训练的 WM/Actor 更新保持正确依赖。多 seed 仅在配方稳定、资源实际允许后并行，不互相覆盖结果。
- 首个接触试验保存初态及 Actor update 50/200/1000 的诊断节点，之后每 1,000 更新做开发评估；评测耗时较大时可在启动前调整间隔并登记。每 10,000 更新汇总一次模式与覆盖。它们是诊断节点，不是预期成功次数或必须凑满的训练量。
- 沿用总计划的每新增 50,000 Actor updates 一个诊断区块；到门槛立即推进。能力改善可以自主续接；同配方连续两个区块无成功数或主要失败模式改善，先做针对性诊断，有可检验改动再续跑；没有新证据时冻结限制，不无限重复。
- 不设后台强制墙钟结束时间；episode 物理时长和阶段超时继续作为任务定义。跨日任务按北京时间追加当日进展，不能因为写日记而杀掉训练。
- 每次启动记录 seed、起始权重、实际配置、独立数据身份、计数、命令、进程/会话和输出位置。当前旧恢复接口不是完整状态续训；若新任务要可靠续接，保存必要的 optimizer、normalizer、replay/采样器与 RNG 等状态；未保存则诚实记录 warm start，不虚报无缝 resume。

### 失败时按证据处理

| 现象 | 先查什么 | 产出 |
| --- | --- | --- |
| 新采教师也不能形成接触 | held-action 与高频教师差别、动作范围、伺服/偏置、模型和初始化 | 高频/目标频率同条件对照，明确是教师还是接口限制 |
| 模型短时准确、接触切换后发散 | 终止边界、门相对几何、夹指残差、数据模式覆盖 | 分事件误差和针对性补采，不只加训练步数 |
| 模型可用、策略不改善 | 动作幅度/饱和、梯度、回报上界、终止价值、观测缺失 | 有名称的单项诊断或变体，保留基线 |
| 片段通过、全程失败 | RSI 依赖、参考时钟、累积偏差、早段失败导致后段数据缺失 | 全程失败事件和必要课程/数据调整，不拼片段 |
| 两单侧通过、共同模型退化 | 任务采样、参考编码、数据占比和遗忘 | 同一检查点两侧结果，记录统一模型是否成立 |
| Warp 通过、原生失败 | 版本、求解器、接触、映射和参数 | 后端分表与具体差异，不静默放宽任务门槛 |
